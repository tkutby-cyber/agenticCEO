# Autonomous Revenue Engine

Persistent operating state for the autonomous revenue experiment.

## Objective
Generate real third-party revenue and evolve toward a repeatable closed-loop mechanism.

## Loop
1. Observe demand and funnel evidence.
2. Select one measurable hypothesis.
3. Build an asset/offer.
4. Distribute through compliant channels.
5. Measure real response and payments.
6. Scale, mutate, or kill.

## Economic constraints
- Total experimental budget: R$1,000.
- Default incremental spend: R$0.
- Leads, credits, promises and unrealized value are not revenue.
- Ledger source of truth: `state.json`.

## Current experiment
Synthetic-media distribution is the first build branch, not a permanent commitment. The system should pivot when evidence favors another mechanism.
